# AlexMartins_v3

Quero construir uma Landing Page profissional utilizando React + TypeScript + Vite + Tailwind CSS + shadcn/ui.

NÃO quero finalizar a landing page nesta etapa.

O objetivo desta primeira versão é criar SOMENTE a estrutura do projeto e a arquitetura visual.

Esta Landing Page será publicada posteriormente na Vercel e o código será versionado no GitHub.

Portanto, o projeto deve nascer organizado, limpo e de fácil manutenção.

====================================================

OBJETIVO

A Landing Page pertence a um consultor patrimonial e representante autorizado Ademicon.

O objetivo NÃO é vender consórcio imediatamente.

O objetivo é transmitir confiança e levar o visitante a iniciar uma conversa pelo WhatsApp.

Toda decisão de layout deve priorizar clareza, simplicidade e credibilidade.

A página deve parecer um consultor explicando um assunto importante, e não uma página promocional.
